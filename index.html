UnlistedStox.com

OTC Equity Pricing & Valuation Platform

unlistedstox.com

Engineering Problem

Unlisted equity transactions in India happen through informal dealer networks without centralized order books. Prices fluctuate across multiple brokerage sheets with wide bid/ask spreads and no automated verification against statutory filings.

Architecture & Storage

Built Node.js and Express REST services to ingest raw transaction confirmations from dealer desks. A background Python evaluation worker compares trade prices against historical round valuations, debt-to-equity ratios, and financial metrics. Stored in PostgreSQL with B-tree indices on(ticker_symbol, trade_timestamp)to support time-window queries under 15ms.

Hospital Management WhatsApp Webhook

Patient Triage, Slot Scheduling & Report Dispatch

Webhook Ingestion: Express.js webhook listener verifying HMAC-SHA256 signatures on every incoming message payload. Achieves sub-200ms acknowledgement to Meta servers to prevent automatic retries.

Financial Market Scrapers & Queue Broker

Deduplication Engine & Async Message Queue

Deduplication: Multi-worker Python Scrapy cluster containerized in Docker. Redis in-memory cache running SHA-256 fingerprinting on URL paths and DOM contents to ensure zero duplicate extractions.

Rate Limiting: Enforces sliding-window request throttling per upstream domain to comply with target server policies.

Decoupled Queue: Parsed JSON records are published to a RabbitMQ topic exchange with dead-letter queue (DLX) fallbacks, decoupling high-throughput extraction from PostgreSQL batch writes.
