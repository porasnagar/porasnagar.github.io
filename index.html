LumaVoice: Hindi lip reading from silent video (2025)

A CNN-LSTM spatio-temporal network in PyTorch that classifies phonemes from the mouth region at 30 FPS, behind a FastAPI service and a React front end that takes uploads or a live webcam.

DJQ-STR: Crowd counting and incident reasoning on video (2026)

CCTV operators need two answers at once: how many people are here, and is something going wrong. Single-purpose models give one or the other.

One checkpoint that bundles a DINOv3 density counter, a V-JEPA motion encoder and a Qwen2.5-VL reasoner. Every change ships only if it beats criteria I register before running the evaluation.

Built with PyTorch, DINOv3, V-JEPA, Qwen2.5-VL, vLLM, Docker, Modal

Broker Cluster: Distributed scraping at 10,480 pages a minute (2025)

Fan-out scrapers either flood the target or drown in duplicates. Throughput is only useful if every page lands exactly once.

A back-pressured fan-out cluster on a RabbitMQ topic exchange, with Redis SHA-256 fingerprints so ingestion stays duplicate-free. Measured at 10,480 pages per minute.

Built with Python, RabbitMQ, Redis, Docker

Triage Gateway: Hospital booking over WhatsApp (2025)

Meta’s Cloud API drops webhooks that are not acknowledged within 200 ms, and a hospital cannot lose a patient’s message.

An Express webhook that verifies HMAC-SHA256 signatures, acknowledges in 142 ms, then handles booking and encrypted report delivery asynchronously.

Built with Node.js, Express, Meta Cloud API, Queues

FMCG Intel: Agents that track M&A news and write the newsletter (2026)

Deal news in consumer goods is scattered across hundreds of outlets and repeated endlessly. Analysts need the deals, once, with context.

A pipeline of agents: news ingestion from Tavily, event extraction with Gemini, relevance and duplicate filtering over pgvector, and a writer agent that turns recent deals into a newsletter.

Built with TypeScript, Tavily, Gemini, PostgreSQL, pgvector
